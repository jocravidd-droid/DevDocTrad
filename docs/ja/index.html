DevDocTrad

1.1 の新機能：動画の音声を字幕に翻訳

技術ドキュメントやプログラマー向けサイトを、コードには一切触れずにあなたの言語へ忠実に翻訳します。

Chrome・Edge・Brave にインストール · ストアに近日公開 Firefox にインストール コードを見る

忠実。正確。無料。

外国語のドキュメントに苦労しているすべての人へ：公式ドキュメント、GitHub の README や issue、Stack Overflow、フォーラム、技術ブログ、カンファレンスの講演。

忠実な翻訳

一文ずつ、同じ順序で、要約も省略も追加もしません。拡張機能は翻訳するだけで、説明はしません。

コードはそのまま

コマンド、関数、API、パス、URL は決して翻訳しません。リンク、太字、コードブロックもそのままの位置に残ります。

あなたの言語で

標準ではブラウザーの言語、37 言語から。ロシアの開発者にはロシア語、日本の開発者には日本語。

動画の音声も翻訳

チュートリアルや講演：字幕を動画の上でリアルタイムに翻訳、YouTube にも対応。字幕がない？音声を無料で文字起こし（Groq Whisper）。読み上げも選べます。

本当に無料

Gemini、Groq、Mistral、OpenRouter の無料枠、またはローカルの Ollama。有料キーは上限を設定するまでブロックされます。

原文・訳文・対訳

本文を置き換えるか、各文の下に訳を表示。クリック一つか Alt+Shift+T で元の原文にそのまま戻ります。

プライバシー重視

統計もトラッキングもなし。キーはブラウザー内に保存。機密性の高いページは自動翻訳しません。

スクリーンショット

インストール

ストア公開までは、数クリックで手動インストールできます。

Chrome · Edge · Brave

  1. devdoctrad-chrome-1.1.0.zip をダウンロードし、残しておくフォルダーに展開します。
  2. chrome://extensions（または edge://extensions、brave://extensions）を開きます。
  3. デベロッパー モードをオンにします。
  4. パッケージ化されていない拡張機能を読み込むをクリックし、展開したフォルダーを選びます。

Firefox

  1. devdoctrad-firefox-1.1.0.zip をダウンロードします。
  2. about:debugging#/runtime/this-firefox を開きます。
  3. 一時的なアドオンを読み込むをクリックし、zip ファイルを選びます。
  4. Firefox 140 以降。正式公開までは、Firefox を閉じるとアドオンが消えます。

次に、無料のキー

  1. 拡張機能の設定を開きます（ポップアップの歯車）。
  2. 無料のキーを作成：Google AI Studio（請求設定なし）、Groq、Mistral（無料モード）、OpenRouter（:free モデル）、または Ollama をインストール。字幕のない動画の音声には Groq を使います。
  3. キーを貼り付け、モデルを読み込むをクリックして一つ選び、テストします。
  4. ページでこのページを翻訳をクリックするか Alt+Shift+T を押します。動画は Alt+Shift+V。

よくある質問

本当に無料ですか？

はい。拡張機能は無料でオープンソースです。各サービスの無料枠であなた自身のキーを使うか、パソコン上の Ollama を使います。有料キーに切り替わることはなく、有料キーはあなたが自分で 1 日の上限を設定するまでブロックされます。

ブラウザー標準の翻訳と何が違うのですか？

標準の翻訳は関数名やコマンド、ときにはコードまで翻訳してしまい、レイアウトもよく崩れます。DevDocTrad はコード、識別子、URL を検出して一切触れず、リンクや書式を保ち、原文と訳文を並べて表示することもできます。

動画の音声翻訳はどう動くのですか？

ポップアップで「動画の音声を翻訳」をオンにするか、Alt+Shift+V を押します。動画に字幕があれば（YouTube、講演、講座）、字幕を翻訳して映像の上に表示します。なければ、音声を数秒ずつに区切り、あなたの無料 Groq キーで Groq Whisper が文字起こしし、それを翻訳します。スピーカーボタンでブラウザーの音声が訳文を読み上げます。費用は一切かかりません。

キーは安全ですか？

キーはブラウザーのローカルストレージにだけ保存され、同期されず、対応するサービスにだけ送られます。URL、ログ、ページへのメッセージに出ることはありません。

ページの文章はどこに送られますか？

あなたが選んだサービスだけです。Ollama ならどこにも送られません。無料枠では Google と Mistral が文章を再利用する場合があります：非公開のページには Ollama がおすすめです。音声については、短い音声の断片だけが Groq に送られます。

対応言語は？

翻訳先は 37 言語：日本語、英語、フランス語、スペイン語、ドイツ語、ロシア語、中国語、韓国語、アラビア語など。ページはどの言語でもかまいません。拡張機能の画面は 36 言語に対応し（アラビア語、ヘブライ語、ペルシア語は右から左）、ブラウザーの言語に従います。このサイトも 37 言語で読めます。

コードを再利用できますか？

はい、MIT ライセンスです。ライセンス表示を残せば、再利用・改変・再配布できます。
