1.1의 새 기능: 동영상 음성을 자막으로 번역

기술 문서와 개발자용 사이트를 코드는 전혀 건드리지 않고 사용자의 언어로 충실하게 번역합니다.

Chrome, Edge, Brave에 설치 · 곧 스토어 출시 Firefox에 설치 코드 보기

충실하게. 정확하게. 무료로.

외국어 문서로 고생하는 모든 분을 위해: 공식 문서, GitHub README와 이슈, Stack Overflow, 포럼, 기술 블로그, 콘퍼런스 발표.

충실한 번역

문장 단위로, 같은 순서로, 요약·생략·추가 없이. 확장 프로그램은 번역만 하고 설명하지 않습니다.

코드는 그대로

명령어, 함수, API, 경로, URL은 절대 번역하지 않습니다. 링크, 굵은 글씨, 코드 블록도 제자리에 그대로 둡니다.

사용자의 언어로

기본값은 브라우저 언어이며 37개 언어를 지원합니다. 러시아 개발자는 러시아어로, 일본 개발자는 일본어로.

동영상 음성 번역

튜토리얼과 발표: 자막을 동영상 위에서 실시간으로 번역하며 YouTube도 지원합니다. 자막이 없다면? 음성을 무료로 받아씁니다(Groq Whisper). 소리 내어 읽기도 선택할 수 있습니다.

진짜 무료

Gemini, Groq, Mistral, OpenRouter의 무료 등급 또는 로컬 Ollama. 유료 키는 한도를 설정하기 전까지 차단됩니다.

원문, 번역 또는 이중 언어

본문을 바꾸거나 각 문장 아래에 번역을 표시합니다. 클릭 한 번이나 Alt+Shift+T로 원문 그대로 돌아갑니다.

개인 정보 보호

통계도 추적도 없습니다. 키는 브라우저에 저장됩니다. 민감한 페이지는 절대 자동 번역하지 않습니다.

스크린샷

설치

스토어에 출시되기 전까지는 몇 번의 클릭으로 직접 설치합니다.

Chrome · Edge · Brave

  1. devdoctrad-chrome-1.1.0.zip을(를) 내려받아 계속 보관할 폴더에 압축을 풉니다.
  2. chrome://extensions(또는 edge://extensions, brave://extensions)을(를) 엽니다.
  3. 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고 압축을 푼 폴더를 선택합니다.

Firefox

  1. devdoctrad-firefox-1.1.0.zip을(를) 내려받습니다.
  2. about:debugging#/runtime/this-firefox을(를) 엽니다.
  3. 임시 부가 기능 로드를 누르고 zip 파일을 선택합니다.
  4. Firefox 140 이상. 정식 출시 전까지는 Firefox를 닫으면 부가 기능이 사라집니다.

그다음, 무료 키

  1. 확장 프로그램 설정을 엽니다(팝업의 톱니바퀴).
  2. 무료 키 만들기: Google AI Studio(결제 연결 없음), Groq, Mistral(무료 모드) 또는 OpenRouter(:free 모델), 또는 Ollama 설치. 자막 없는 동영상 음성에는 Groq를 사용하세요.
  3. 키를 붙여 넣고 모델 불러오기를 눌러 하나를 고른 뒤 테스트합니다.
  4. 페이지에서 이 페이지 번역을 누르거나 Alt+Shift+T를 누릅니다. 동영상은 Alt+Shift+V.

자주 묻는 질문

정말 무료인가요?

네. 확장 프로그램은 무료이며 오픈 소스입니다. 각 서비스의 무료 등급에서 사용자의 키를 쓰거나 컴퓨터의 Ollama를 사용합니다. 유료 키로 넘어가는 일은 없으며, 유료 키는 사용자가 직접 일일 한도를 설정하기 전까지 차단됩니다.

브라우저 내장 번역과 무엇이 다른가요?

내장 번역은 함수 이름, 명령어, 때로는 코드까지 번역하고 레이아웃도 자주 깨뜨립니다. DevDocTrad는 코드, 식별자, URL을 감지해 절대 건드리지 않고, 링크와 서식을 유지하며, 원문과 번역을 나란히 보여 줄 수도 있습니다.

동영상 음성 번역은 어떻게 작동하나요?

팝업에서 「동영상 음성 번역」을 켜거나 Alt+Shift+V를 누르세요. 동영상에 자막이 있으면(YouTube, 발표, 강의) 자막을 번역해 화면 위에 표시합니다. 없으면 소리를 몇 초 단위로 잘라 무료 Groq 키로 Groq Whisper가 받아쓰고, 이를 번역합니다. 스피커 버튼은 브라우저 음성으로 번역을 읽어 줍니다. 비용은 전혀 들지 않습니다.

제 키는 안전한가요?

키는 브라우저의 로컬 저장소에만 저장되고, 동기화되지 않으며, 해당 서비스에만 전송됩니다. URL, 로그, 페이지로 보내는 메시지에 절대 나타나지 않습니다.

페이지 텍스트는 어디로 가나요?

사용자가 선택한 서비스로만 가고, Ollama를 쓰면 어디에도 가지 않습니다. 무료 등급에서는 Google과 Mistral이 텍스트를 재사용할 수 있으니 비공개 페이지에는 Ollama를 권장합니다. 음성은 짧은 오디오 조각만 Groq로 전송됩니다.

어떤 언어를 지원하나요?

한국어, 영어, 프랑스어, 스페인어, 독일어, 러시아어, 중국어, 일본어, 아랍어 등 37개 대상 언어. 페이지는 어떤 언어여도 됩니다. 확장 프로그램 화면은 36개 언어로 제공되며(아랍어, 히브리어, 페르시아어는 오른쪽에서 왼쪽) 브라우저 언어를 따릅니다. 이 사이트도 37개 언어로 제공됩니다.

코드를 재사용해도 되나요?

네, MIT 라이선스입니다. 라이선스 고지를 유지하면 재사용, 수정, 재배포할 수 있습니다.
