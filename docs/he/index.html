חדש בגרסה 1.2: דיבוב סרטונים בכל אתר

מתרגם בנאמנות תיעוד טכני ואתרים למתכנתים לשפה שלך, בלי לגעת אף פעם בקוד.

התקנה ב-Chrome, Edge, Brave · בקרוב בחנויות התקנה ב-Firefox צפייה בקוד

נאמן. מדויק. חינמי.

לכל מי שנאבק בתיעוד בשפה זרה: תיעוד רשמי, קובצי README ו-issues ב-GitHub, Stack Overflow, פורומים, בלוגים טכניים, הרצאות מכנסים.

תרגום נאמן

משפט אחר משפט, באותו סדר, בלי סיכום, השמטה או תוספת. התוסף מתרגם, הוא לא מסביר.

הקוד נשאר שלם

פקודות, פונקציות, ממשקי API, נתיבים וכתובות URL לעולם אינם מתורגמים. קישורים, טקסט מודגש ובלוקי קוד נשארים במקומם.

בשפה שלך

כברירת מחדל שפת הדפדפן, מתוך 37 שפות. מפתח רוסי מקבל רוסית, מפתח יפני מקבל יפנית.

הקול בסרטונים מתורגם

מדריכים והרצאות: הכתוביות מתורגמות בזמן אמת על הסרטון, גם ב-YouTube. אין כתוביות? הקול מתומלל בחינם (Groq Whisper). הקראה בקול לבחירה. דיבוב: התרגום נאמר בקול של הדפדפן.

באמת חינמי

המסלולים החינמיים של Gemini, Groq, Mistral, OpenRouter, או Ollama מקומית. מפתח בתשלום נשאר חסום עד שתגדיר תקרה.

מקור, תרגום או דו־לשוני

מחליף את הטקסט או מציג את התרגום מתחת לכל משפט. לחיצה אחת או Alt+Shift+T חזרה למקור המדויק.

פרטי

בלי סטטיסטיקות ובלי מעקב. המפתחות נשמרים בדפדפן שלך. דפים רגישים לעולם אינם מתורגמים אוטומטית.

נסה על קטע לדוגמה

קטע תיעוד באנגלית. החלף מצב: הטקסט עובר לשפה שלך, הקוד לא זז.

Reading a configuration fileקריאת קובץ הגדרות

Call readFile() to load the file, then JSON.parse() to turn it into an object.קרא ל-readFile() כדי לטעון את הקובץ, ואז ל-JSON.parse() כדי להפוך אותו לאובייקט.

import { readFile } from "node:fs/promises";

const text = await readFile("config.json", "utf8");
const config = JSON.parse(text);

הקול בסרטונים, ככתוביות

הרצאה באנגלית: התרגום מופיע בזמן אמת על התמונה, מתחת למשפט המקורי. כאן זו הדמיה.

סרטון ההיכרות

צילומי מסך

התקנה

Firefox: בלחיצה אחת מ-addons.mozilla.org. Chrome, Edge ו-Brave: ידנית בכמה לחיצות, עד הפרסום בחנויות.

Chrome · Edge · Brave

  1. הורד את devdoctrad-chrome-1.3.0.zip (1.3.0) וחלץ אותו לתיקייה שתשמור.
  2. פתח את chrome://extensions (או edge://extensions, brave://extensions).
  3. הפעל את מצב מפתח.
  4. לחץ על טעינת פריט לא ארוז ובחר את התיקייה שחולצה.

Firefox

התקנה מ-addons.mozilla.org

Firefox 140 ומעלה. העדכונים מגיעים מעצמם.

או ידנית, עם קובץ ה-zip
  1. הורד את devdoctrad-firefox-1.3.0.zip (1.3.0).
  2. פתח את about:debugging#/runtime/this-firefox.
  3. לחץ על טעינת תוספת זמנית ובחר את קובץ ה-zip.
  4. תוספת שנטענת כך היא זמנית: היא נעלמת כשסוגרים את Firefox.

ואז, מפתח חינמי

  1. פתח את הגדרות התוסף (גלגל השיניים בחלון הקופץ).
  2. צור מפתח חינמי: Google AI Studio (בלי חיוב), Groq, Mistral (מצב חינמי) או OpenRouter (מודלים :free), או התקן את Ollama. לקול בסרטונים בלי כתוביות, השתמש ב-Groq.
  3. הדבק את המפתח, לחץ על טעינת מודלים, בחר אחד ואז בדיקה.
  4. בדף כלשהו, לחץ על תרגום הדף או הקש Alt+Shift+T. לסרטון: Alt+Shift+V.

שאלות נפוצות

זה באמת חינמי?

כן. התוסף חינמי ובקוד פתוח. הוא משתמש במפתחות שלך במסלולים החינמיים של הספקים, או ב-Ollama במחשב שלך. הוא לעולם לא עובר למפתח בתשלום, ומפתח בתשלום נשאר חסום עד שאתה עצמך מגדיר תקרה יומית.

במה זה שונה מהתרגום המובנה של הדפדפן?

התרגום המובנה מתרגם גם שמות של פונקציות, פקודות ולפעמים קוד, ולעתים קרובות שובר את הפריסה. DevDocTrad מזהה קוד, מזהים וכתובות URL ולעולם לא נוגע בהם, שומר על קישורים ועיצוב, ויכול להציג את המקור והתרגום זה לצד זה.

איך עובד תרגום הקול בסרטונים?

הפעל את „תרגום הקול בסרטונים” בחלון הקופץ או הקש Alt+Shift+V. אם לסרטון יש כתוביות (YouTube, הרצאות, קורסים), הן מתורגמות ומוצגות על התמונה. אחרת הקול נחתך לקטעים של כמה שניות, מתומלל על ידי Groq Whisper עם מפתח ה-Groq החינמי שלך, ואז מתורגם. כפתור הרמקול מקריא את התרגום בקול הדפדפן. שום דבר אינו בתשלום. לדיבוב, בחר „כתוביות + קול מתורגם (דיבוב)”: הקול של הדפדפן אומר את התרגום בתזמון עם הסרטון.

האם המפתחות שלי בטוחים?

הם נשמרים רק באחסון המקומי של הדפדפן, אינם מסונכרנים לעולם ונשלחים רק לספק המתאים. הם לעולם לא מופיעים בכתובת URL, ביומן או בהודעה שנשלחת לדף.

לאן הולך הטקסט של הדפים?

רק לספק שבחרת, או לשום מקום עם Ollama. במסלולים החינמיים Google ו-Mistral עשויות לעשות שימוש חוזר בטקסט: לדפים פרטיים עדיף Ollama. בקול, רק קטעי שמע קצרים נשלחים ל-Groq.

אילו שפות?

37 שפות יעד, ביניהן עברית, אנגלית, צרפתית, ספרדית, גרמנית, רוסית, סינית, יפנית וערבית. הדפים יכולים להיות בכל שפה. ממשק התוסף זמין ב-36 שפות (ערבית, עברית ופרסית מימין לשמאל) ועוקב אחרי הדפדפן. גם האתר הזה זמין ב-37 שפות.
