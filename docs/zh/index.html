1.1 新功能：视频语音翻译成字幕

将技术文档和面向程序员的网站忠实翻译成你的语言，绝不改动代码。

安装到 Chrome、Edge、Brave · 即将上架应用商店 安装到 Firefox 查看代码

忠实。精确。免费。

献给所有被外语文档困扰的人：官方文档、GitHub 的 README 和 issue、Stack Overflow、论坛、技术博客、会议演讲。

忠实翻译

逐句翻译，顺序不变，不概括、不省略、不添加。扩展只翻译，不解释。

代码保持原样

命令、函数、API、路径和 URL 绝不翻译。链接、粗体和代码块都留在原处。

用你的语言

默认使用浏览器语言，支持 37 种语言。俄罗斯开发者看到俄语，日本开发者看到日语。

视频语音翻译

教程和演讲：字幕直接在视频上实时翻译，包括 YouTube。没有字幕？语音免费转写（Groq Whisper）。可选朗读。

真正免费

使用 Gemini、Groq、Mistral、OpenRouter 的免费额度，或本地的 Ollama。付费密钥在你设置上限之前一直被锁定。

原文、译文或双语

替换原文，或在每句下方显示译文。点一下或按 Alt+Shift+T 即可回到完全一致的原文。

注重隐私

无统计，无跟踪。密钥保存在你的浏览器中。敏感页面绝不自动翻译。

安装

Firefox：在 addons.mozilla.org 一键安装。Chrome、Edge 和 Brave：在上架应用商店之前，点几下即可手动安装。

Chrome · Edge · Brave

  1. 下载 devdoctrad-chrome-1.2.0.zip，解压到一个会保留的文件夹中。
  2. 打开 chrome://extensions（或 edge://extensions、brave://extensions）。
  3. 开启开发者模式。
  4. 点击加载已解压的扩展程序，选择解压后的文件夹。

Firefox

从 addons.mozilla.org 安装

需要 Firefox 140 或更高版本。更新会自动推送。

或者用 zip 文件手动安装
  1. 下载 devdoctrad-firefox-1.2.0.zip。
  2. 打开 about:debugging#/runtime/this-firefox。
  3. 点击临时载入附加组件，选择 zip 文件。
  4. 这样载入的附加组件是临时的：关闭 Firefox 后就会消失。

然后，一个免费密钥

  1. 打开扩展设置（弹出窗口中的齿轮）。
  2. 创建免费密钥：Google AI Studio（不绑定结算）、Groq、Mistral（免费模式）或 OpenRouter（:free 模型），或安装 Ollama。没有字幕的视频语音请使用 Groq。
  3. 粘贴密钥，点击加载模型，选择一个，然后点测试。
  4. 在网页上点击翻译此页面或按 Alt+Shift+T。视频：Alt+Shift+V。

常见问题

真的免费吗？

是的。扩展免费且开源。它在服务商的免费额度上使用你自己的密钥，或使用你电脑上的 Ollama。它绝不会切换到付费密钥，而付费密钥在你亲自设置每日上限之前一直被锁定。

和浏览器自带的翻译有什么不同？

自带翻译会把函数名、命令甚至代码也翻译掉，还常常破坏排版。DevDocTrad 能识别代码、标识符和 URL 并且绝不改动它们，保留链接和格式，还能并排显示原文和译文。

视频语音翻译是怎么工作的？

在弹出窗口中打开「翻译视频中的语音」，或按 Alt+Shift+V。如果视频有字幕（YouTube、演讲、课程），字幕会被翻译并显示在画面上。否则，声音会被切成几秒钟的片段，由 Groq Whisper 使用你的免费 Groq 密钥转写，再进行翻译。扬声器按钮会用浏览器的语音朗读译文。全程不花一分钱。

我的密钥安全吗？

密钥只保存在浏览器的本地存储中，从不同步，只发送给对应的服务商。它们绝不会出现在 URL、日志或发送给网页的消息中。

页面文字会发送到哪里？

只发送给你选择的服务商，使用 Ollama 时则哪儿也不去。在免费额度下，Google 和 Mistral 可能会重复使用文字：私密页面建议用 Ollama。语音方面，只有很短的音频片段会发送给 Groq。

支持哪些语言？

37 种目标语言，包括简体中文、繁体中文、英语、法语、西班牙语、德语、俄语、日语和阿拉伯语。页面可以是任何语言。扩展界面提供 36 种语言（阿拉伯语、希伯来语和波斯语从右到左显示），并跟随浏览器语言。本网站也提供 37 种语言。

我可以使用这些代码吗？

可以，MIT 许可证：只要保留许可声明，你就可以使用、修改和再发布。
