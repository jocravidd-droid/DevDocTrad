ใหม่ในเวอร์ชัน 1.1: แปลเสียงในวิดีโอเป็นคำบรรยาย

แปลเอกสารเทคนิคและเว็บไซต์สำหรับโปรแกรมเมอร์เป็นภาษาของคุณอย่างตรงต้นฉบับ โดยไม่แตะต้องโค้ดเลย

ติดตั้งบน Chrome, Edge, Brave · เร็ว ๆ นี้ในร้านค้า ติดตั้งบน Firefox ดูโค้ด

ตรงต้นฉบับ แม่นยำ ฟรี

สำหรับทุกคนที่ลำบากกับเอกสารภาษาต่างประเทศ: เอกสารทางการ, README และ issue บน GitHub, Stack Overflow, ฟอรัม, บล็อกเทคนิค, การบรรยายในงานสัมมนา

แปลตรงต้นฉบับ

ทีละประโยค ตามลำดับเดิม ไม่สรุป ไม่ตัดทอน ไม่เพิ่มเติม ส่วนขยายนี้แปล ไม่ได้อธิบาย

โค้ดยังคงเดิม

คำสั่ง ฟังก์ชัน API พาธ และ URL จะไม่ถูกแปลเลย ลิงก์ ตัวหนา และบล็อกโค้ดอยู่ที่เดิม

เป็นภาษาของคุณ

ค่าเริ่มต้นคือภาษาของเบราว์เซอร์ จาก 37 ภาษา นักพัฒนาชาวรัสเซียได้ภาษารัสเซีย ชาวญี่ปุ่นได้ภาษาญี่ปุ่น

แปลเสียงในวิดีโอ

บทเรียนและการบรรยาย: คำบรรยายถูกแปลสดบนวิดีโอ รวมถึง YouTube ไม่มีคำบรรยาย? เสียงจะถูกถอดความฟรี (Groq Whisper) อ่านออกเสียงได้ตามต้องการ

ฟรีจริง

แพ็กเกจฟรีของ Gemini, Groq, Mistral, OpenRouter หรือ Ollama ในเครื่อง คีย์แบบเสียเงินจะถูกบล็อกจนกว่าคุณจะตั้งเพดาน

ต้นฉบับ คำแปล หรือสองภาษา

แทนที่ข้อความ หรือแสดงคำแปลใต้แต่ละประโยค คลิกเดียวหรือ Alt+Shift+T เพื่อกลับไปที่ต้นฉบับตรงตัว

เป็นส่วนตัว

ไม่มีสถิติ ไม่มีการติดตาม คีย์เก็บอยู่ในเบราว์เซอร์ของคุณ หน้าที่ละเอียดอ่อนจะไม่ถูกแปลอัตโนมัติ

ภาพหน้าจอ

การติดตั้ง

ระหว่างรอเผยแพร่ในร้านค้า ติดตั้งด้วยตนเองได้ในไม่กี่คลิก

Chrome · Edge · Brave

  1. ดาวน์โหลด devdoctrad-chrome-1.1.0.zip แล้วแตกไฟล์ไว้ในโฟลเดอร์ที่คุณจะเก็บไว้
  2. เปิด chrome://extensions (หรือ edge://extensions, brave://extensions)
  3. เปิด โหมดนักพัฒนาซอฟต์แวร์
  4. คลิก โหลดส่วนขยายที่คลายการบีบอัด แล้วเลือกโฟลเดอร์ที่แตกไฟล์

Firefox

  1. ดาวน์โหลด devdoctrad-firefox-1.1.0.zip
  2. เปิด about:debugging#/runtime/this-firefox
  3. คลิก โหลดส่วนเสริมชั่วคราว แล้วเลือกไฟล์ zip
  4. Firefox 140 ขึ้นไป ส่วนเสริมจะหายไปเมื่อปิด Firefox จนกว่าจะเผยแพร่อย่างเป็นทางการ

จากนั้น คีย์ฟรี

  1. เปิดการตั้งค่าของส่วนขยาย (รูปเฟืองในป๊อปอัป)
  2. สร้างคีย์ฟรี: Google AI Studio (ไม่ต้องผูกการเรียกเก็บเงิน), Groq, Mistral (โหมดฟรี) หรือ OpenRouter (โมเดล :free) หรือติดตั้ง Ollama สำหรับเสียงในวิดีโอที่ไม่มีคำบรรยาย ให้ใช้ Groq
  3. วางคีย์ คลิก โหลดโมเดล เลือกหนึ่งโมเดล แล้วคลิก ทดสอบ
  4. บนหน้าเว็บ คลิก แปลหน้านี้ หรือกด Alt+Shift+T สำหรับวิดีโอ: Alt+Shift+V

คำถามที่พบบ่อย

ฟรีจริงหรือ?

จริง ส่วนขยายนี้ฟรีและเป็นโอเพนซอร์ส ใช้คีย์ของคุณเองบนแพ็กเกจฟรีของผู้ให้บริการ หรือ Ollama บนคอมพิวเตอร์ของคุณ ไม่เคยเปลี่ยนไปใช้คีย์แบบเสียเงิน และคีย์แบบเสียเงินจะถูกบล็อกจนกว่าคุณจะตั้งเพดานรายวันเอง

ต่างจากการแปลในตัวของเบราว์เซอร์อย่างไร?

การแปลในตัวจะแปลชื่อฟังก์ชัน คำสั่ง และบางครั้งแม้แต่โค้ด และมักทำให้เลย์เอาต์พัง DevDocTrad ตรวจจับโค้ด ชื่อตัวแปร และ URL เพื่อไม่แตะต้องเลย คงลิงก์และการจัดรูปแบบไว้ และแสดงต้นฉบับคู่กับคำแปลได้

การแปลเสียงในวิดีโอทำงานอย่างไร?

เปิด «แปลเสียงในวิดีโอ» ในป๊อปอัป หรือกด Alt+Shift+V ถ้าวิดีโอมีคำบรรยาย (YouTube การบรรยาย คอร์สเรียน) คำบรรยายจะถูกแปลและแสดงบนภาพ ถ้าไม่มี เสียงจะถูกตัดเป็นช่วงละไม่กี่วินาที ถอดความโดย Groq Whisper ด้วยคีย์ Groq ฟรีของคุณ แล้วจึงแปล ปุ่มลำโพงจะอ่านคำแปลออกเสียงด้วยเสียงของเบราว์เซอร์ ไม่มีอะไรต้องจ่ายเงิน

คีย์ของฉันปลอดภัยไหม?

คีย์เก็บไว้ในพื้นที่จัดเก็บในเครื่องของเบราว์เซอร์เท่านั้น ไม่มีการซิงค์ และส่งไปยังผู้ให้บริการที่ตรงกันเท่านั้น คีย์จะไม่ปรากฏใน URL บันทึก หรือข้อความที่ส่งไปยังหน้าเว็บ

ข้อความของหน้าเว็บถูกส่งไปที่ไหน?

ไปยังผู้ให้บริการที่คุณเลือกเท่านั้น หรือไม่ไปไหนเลยเมื่อใช้ Ollama ในแพ็กเกจฟรี Google และ Mistral อาจนำข้อความไปใช้ซ้ำ: สำหรับหน้าส่วนตัว ควรใช้ Ollama สำหรับเสียง จะส่งเพียงเสียงช่วงสั้น ๆ ไปยัง Groq

รองรับภาษาอะไรบ้าง?

37 ภาษาปลายทาง รวมถึงไทย อังกฤษ ฝรั่งเศส สเปน เยอรมัน รัสเซีย จีน ญี่ปุ่น และอาหรับ หน้าเว็บจะเป็นภาษาใดก็ได้ อินเทอร์เฟซของส่วนขยายมี 36 ภาษา (อาหรับ ฮีบรู และเปอร์เซียแสดงจากขวาไปซ้าย) และเป็นไปตามเบราว์เซอร์ เว็บไซต์นี้ก็มี 37 ภาษาเช่นกัน

ฉันนำโค้ดไปใช้ได้ไหม?
