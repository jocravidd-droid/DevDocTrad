Getting started

Nimbus is a small HTTP client for Node.js that keeps your code readable.

Install the package with npm install nimbus-http, then import the default client in your project.

// Create a client with a base URL
import { createClient } from 'nimbus-http';
const api = createClient({ baseUrl: 'https://api.example.com' });

Every request returns a promise. Use await api.get('/users') to read the response body as JSON, or call response.text() if you need the raw text.

Note: requests time out after 30 seconds by default. You can change this with the timeout option.

Handling errors

When the server answers with a status code of 400 or more, Nimbus throws an HttpError. The error keeps the original response, so you can inspect the headers.

OptionDescription
retriesNumber of times a failed request is sent again.
timeoutMaximum time to wait for an answer, in milliseconds.
